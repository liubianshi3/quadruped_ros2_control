# Dog2 Symmetric Meshes

Generated by `src/dog2_description/scripts/generate_symmetric_meshes_blender.py`.

The leg visual and collision STL files are generated from the front-left `l1*` source meshes in Blender with per-link local-frame mirror rules. This avoids double-mirroring the URDF side-specific joint-frame rotations.

- rail: leg2/leg4 mirror local X
- coxa: all legs keep the front-left local frame
- femur: leg3 mirrors local X; leg4 mirrors local Z for the existing rf visual flip
- tibia: leg3/leg4 mirror local X

The real model continues to use `meshes/`; only `dog2_symmetric.urdf.xacro` uses this directory.
